## 2026-10-01: First implementation decisions and validation
- The engine uses one response when a source has no usable validator; it does not splice unvalidated windows together.
- This milestone rejects unexpected content encoding rather than risking corrupt ranged output. Encoded-response support remains an explicit future decision.
- Buffers are allocated lazily and exclusively owned until ordered platform-thread writes finish. A bounded permit count applies backpressure.
- Single-stream retries restart from zero; validated ranged retries continue from acknowledged positions within a bounded window retry budget.
- Final publication uses a same-filesystem hard link to atomically avoid replacing an existing destination. Filesystems without hard-link support fail safely; portable publication fallback remains pending.
- Failed/canceled partial files are retained and exposed by the handle, but restart resume is not implemented yet.

## 2026-10-01: Parallel range milestone
- The writer currently sets written progress to offset+length and flushes a prefix. Parallel writes require union coverage and snapshots of exact acknowledged intervals.
- Recovery currently truncates to the saved prefix; preserve verified disjoint ranges and reconstruct only gaps. Check partial-file size against the highest durable end, rather than the prefix.
- Use immutable scheduler leases for fixed-concurrency workers. Reserve each write inside its lease and acknowledge it only after positional writing finishes; do not transfer active ownership in this milestone.
- Range rejection requires canceling and joining the whole worker generation before resetting to a single stream. Pause/cancel must reach every response and header wait.
- Existing explicit option constructors preserve one-worker behavior; the default options can start at four workers for sufficiently large validated sources. Persist new options with a versioned SQLite migration.
- Limits should cover active HTTP responses per actual redirect host and in-flight buffer bytes across downloads in one engine. No transport/download helper dependencies are needed.
- The writer's ordered queue can safely serialize positional disk jobs from multiple producers while workers remain concurrent on the network. Snapshot barriers include exact acknowledged intervals, and replay removes only the affected window before retrying it.
- A sparse/full-length partial can contain garbage in every unclaimed gap. Recovery preserves higher saved ranges and overwrites all gaps; truncation is checked against the highest saved end.

## Phase 4: Handoff design
- Existing fixed leases reserve writes after each read. Splitting at the acknowledged offset would overlap a response already in flight.
- Protect the entire current HTTP window under the scheduler lock before sending it. A thief may take only the unrequested tail above the protected window and queued writes. Window retries retain that protection until validation and writes settle.
- Keep fixed mode explicit for comparisons and backward compatibility. Adaptive mode will use a configured maximum, start with two lanes, and evaluate bounded trials using useful acknowledged throughput. Idle workers must wait for future handoffs instead of exiting early.

## Phase 4: Controller and compatibility
- Protected-window and controller tests pass. Stealing chooses the largest estimated completion time and divides its unrequested tail by smoothed lane speeds.
- New adaptive mode is opt-in through withAdaptiveParallelism(maximum, minimumBytes); existing constructors/default fixed mode remain comparable. SQLite schema v3 persists the choice and migrates v1/v2 to fixed mode.
- Controller starts at two lanes, measures a two-second baseline, allows one second of settling, and measures a two-second trial. It requires at least 12% gain; neutral/harmful trials roll back and remain held until a sustained rate change after cooldown.
- No persistent host profiles exist yet. Attempt-local diagnostics contain no URLs or headers and retain at most 256 decisions. Future host hints need separate evidence for expiry and network-change identification.
